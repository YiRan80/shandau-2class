第二课堂抢课辅助程序  v1.0.6
============================================

一、这是什么
  本机运行的抢课辅助工具：自动找到学校第二课堂抢课页、自动登录、
  到「报名开始时间」自动抢你手动确认过的那几门课。
  自带本地网页界面，不需要联网安装任何东西，也不上传任何数据。

二、运行环境
  - Windows 10 / 11
  - Python 3.9 以上（只用标准库，不用 pip 装东西）
  - Chrome 或 Edge（程序会用它打开页面）

  检查 Python：命令行执行  python --version
  没装就去 python.org 下 Windows 安装包，安装时勾选
  "Add Python to PATH"。

三、启动
  双击  启动程序.vbs    不弹黑窗口，自动打开浏览器界面
  双击  启动程序.bat    能看到报错（出问题先试这个）

  启动后浏览器会打开 http://127.0.0.1:8765/
  如果没自动打开，手动复制这个地址到浏览器即可。

  注意：程序已经在运行时，再次双击会「直接打开界面」而不会重复启动，
  这是正常的。

四、停止
  - 界面右上「停止」按钮
  - 或命令行执行  python stop.py

五、第一次使用
  1. 在左侧「登录信息」填学号/账号和密码（可以留空沿用上次）
  2. 点「保存配置」
  3. 点「启动抢课」
  4. 程序会自动：打开校园门户 → 点「登录」→ 进统一身份认证 →
     自动填账号密码并提交
  5. 如果弹出验证码：在自动打开的浏览器里手动输入（程序不认识验证码，
     只等你输入后自动提交，最长等 240 秒）
  6. 登录成功后会自动进入第二课堂活动中心并列出「能报的二课」

六、怎么抢课
  1. 右侧「课程与余量」里点你想抢的课程卡片（变成「待确认」）
  2. 点「确认选课」——只有确认过的课程才会被抢，没确认时程序只刷新列表
  3. 保持程序运行即可：到该课程「报名开始时间」前会自动切成高频刷新，
     到点提交报名
  4. 想改选：再点卡片增删，然后重新点「确认选课」
  5. 想全部取消：点「清空选择」

七、数据放在哪
  data\config.json     你的账号、筛选、抢课计划（明文密码，别外传）
  data\state.json      当前运行状态
  data\results.json    每一轮的结果记录
  data\entry_cache.json 上次成功进入抢课页的地址缓存
  logs\operation.log   全部操作日志（排错看这个）

  删掉 data\ 就等于恢复出厂设置（账号也要重填）。

八、常见问题
  - 界面还是旧样式：按 Ctrl+F5 强制刷新一次
  - 提示端口被占用 / 打不开：说明另一个实例还在跑，
    先 python stop.py，再重新双击
  - 提示「找不到 start_chrome.py」：程序会自己启动浏览器；
    若失败，可以先手动用调试端口启动浏览器，再点启动抢课
  - 到了登录页就停住：左侧没填账号密码，或需要人工点验证码
  - 找不到抢课入口：确认能手动在浏览器里打开活动中心页面；
    或点界面上的「重新发现入口」

九、合规提醒
  只能用自己的账号，请遵守学校平台使用条款；程序遇到验证码一律停下来
  等人工，不破解、不伪造请求；刷新间隔有下限，避免影响平台稳定。
