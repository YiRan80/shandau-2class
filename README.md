# 杉达第二课堂抢课辅助程序 v1.0.6

本地运行的抢课辅助工具：自动发现学校「第二课堂」活动中心入口 → 用本人账号自动登录 →
在你确认过的课程「报名开始时间」自动刷新并提交报名。全部运算在本机完成，不上传任何数据。

> 仅限本人账号、遵守学校平台使用条款。程序遇到验证码一律暂停等待人工输入，不破解、不伪造请求、不并发刷接口。

## 功能

- **入口自动发现**：锚点 → 本地缓存 → 语义匹配（二课 / 活动中心）→ 逐级导航 → DOM 特征确认，逐级定位，任一环失败自动回退，网址变化不用改配置
- **自动登录**：走学校统一身份认证，自动填表提交；出现验证码时暂停并等你手动输入
- **课程视图**：活动列表、余量、报名开始时间，按五育（德/智/体/美/劳）、层级（校级/院级）、校区分类筛选
- **定时抢课**：提前启动 → 打开页面 → 登录 → 就绪 → 到点前切高频刷新 → 提交报名 → 防重复
- **本地界面**：网页控制台、五阶段状态时间线、登录态徽标、全量操作日志、配置导出/导入
- **零第三方依赖**：只用 Python 标准库（`http.server` + 自带 WebSocket 实现的 CDP 客户端）

## 环境要求

- Windows 10 / 11
- Python 3.9 以上（安装时勾选 `Add Python to PATH`）
- Chrome 或 Edge

## 快速开始

```bat
git clone https://github.com/YiRan80/shandau-2class.git
cd shandau-2class
```

双击 `启动程序.vbs`（静默启动，不弹黑窗口），或双击 `启动程序.bat`（能看到报错）。
启动后浏览器会自动打开 <http://127.0.0.1:8765/>。

使用流程：

1. 左侧「登录信息」填学号 / 密码 →「保存配置」
2. 右侧点课程卡片选中（变成「待确认」）→「确认选课」
3. 点「启动抢课」，保持运行即可
4. 停止：界面右上「停止」，或命令行 `python stop.py`

服务端口、监听地址、自动开浏览器都在 `server.py` 顶部「配置区」四个常量里改。
完整步骤与常见问题见 [使用说明.txt](使用说明.txt)。

## 数据与隐私

运行时数据全部生成在项目目录下，已被 `.gitignore` 排除，不会进入仓库：

| 路径 | 内容 |
| --- | --- |
| `data/config.json` | 账号、筛选、抢课计划（**密码明文**，不要外传） |
| `data/state.json` | 当前运行状态 |
| `data/results.json` | 每轮结果记录 |
| `data/entry_cache.json` | 上次成功进入抢课页的地址 |
| `logs/operation.log` | 全部操作日志（排错看这个） |

删掉 `data/` 即恢复出厂设置。程序不联网上报任何数据，也不含分析统计。

## 项目结构

```
shandau_2class/
├─ 启动程序.vbs / 启动程序.bat   # 入口：静默 / 可见日志
├─ server.py                     # 本地 Web 服务 + REST API（配置区在此）
├─ stop.py                       # 停止已在运行的服务
├─ VERSION                       # 版本号
├─ 使用说明.txt                  # 完整使用文档
├─ core/
│  ├─ common.py                  # 配置读写与夹紧、脱敏、日志、锁、结果落盘
│  ├─ discovery.py               # 入口自动发现（四级导航 + 特征确认）
│  ├─ watcher.py                 # 列表快照差异、分类解析与筛选
│  ├─ engine.py                  # 编排：就绪状态机、登录恢复、定时/高频、提交
│  └─ cdp_client.py              # 标准库实现的 CDP 客户端（WebSocket）
└─ web/                          # 本地控制台（原生 JS，无框架）
```
